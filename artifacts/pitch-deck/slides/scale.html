Adding a coast

Every input is global open data. A new coast is a region entry, a language and one build; the outage model is then checked against that grid's own night lights.

Plugging into national alerting

Alerts are CAP 1.2, the format NDMA's SACHET already carries, published on a standard CAP feed. The same build works for any cyclone basin, including the rest of coastal Asia-Pacific.
